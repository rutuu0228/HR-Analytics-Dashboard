# 👥 HR Analytics Dashboard

> Interactive HR analytics dashboard designed to transform employee data into clear workforce insights and decision-support metrics.

## 🎯 Project Objective

The goal of this project is to analyze workforce data and present key HR metrics through an interactive dashboard. The dashboard helps identify patterns related to employee demographics, performance, attrition, and workforce composition.

## 📊 Analysis Areas

The dashboard focuses on:

- Employee headcount and workforce composition
- Employee demographics
- Department and job-role analysis
- Attrition / turnover patterns
- Performance-related metrics
- Workforce distribution and trends

## 🔎 Key Analytical Questions

- What is the overall workforce and attrition picture?
- Which departments or roles have higher attrition?
- How is the workforce distributed across demographic groups?
- Which employee segments require further HR attention?
- What patterns can help improve employee retention and workforce planning?

## 📈 Dashboard KPIs

The dashboard is designed to monitor HR metrics such as:

- Total Employees
- Attrition / Turnover

The project demonstrates how employee data can be transformed into an interactive HR reporting solution that supports **workforce monitoring, attrition analysis, employee segmentation, and data-driven HR decisions**.

1. Open the Power BI report if Power BI Desktop is available.
2. Review the headline HR KPIs.

4. Use the dashboard to identify workforce patterns and areas that may require deeper investigation.
